# pack_to_psv

GenSfen の可変長 `.pack` 棋譜を、40 バイト固定長の PackedSfenValue (PSV) に展開します。
move16 は実着手ラベルを実 YaneuraOu 形式に変換します。

```bash
cargo run --release -p tools --bin pack_to_psv -- \
  --input data.pack --output teacher.psv
```

- `--input` はカンマ区切りで複数ファイルを指定できます。
- `--input-dir` と `--pattern`（既定 `*.pack`）でも入力を指定できます。
  `--input` と `--input-dir` は同時に指定できません。
- `--max-games` の既定値 0 は全対局を処理します。正の値は**全入力ファイルの通算上限**です。
  対局の途中では打ち切らず、指定数の対局を読み終えたところで止まります。
  0手で終局した対局も1局と数え、空ファイルは数えません。上限到達後のデータは検査しません。

入力パスは辞書順に並べ、各ファイルの対局順・指し手順で出力します。
バッチ内の変換は並列ですが、スレッド数を変えても出力バイト列は変わりません。
乱数・seedを使う処理はありません。並列数は `RAYON_NUM_THREADS` で指定できます。

入力は64 KiBのバッファで読み、最大128局・合計16,384局面を目安とするバッチへ分割します。
最後に加える1局は分割しません。1局内の指し手列と局面履歴も、PSVの `game_ply` が
表せる0〜65535の範囲に制限します。これを超える局面は切り詰めたりwrapしたりせずエラーにします。
ファイル一覧を除き、保持するデータ量は総ファイルサイズ・総対局数・総出力サイズに比例しません。

出力には全入力と別の通常ファイルを指定してください。同一パス、いずれかの入力を指す
hardlink、symlink の出力パスは、出力を作成する前に拒否します。
出力先と同じディレクトリの一時ファイルへ書き、変換と書込みがすべて成功した後で出力を置換します。
既存出力がある場合は、既存分と新しい出力分の両方を保持できる空き容量が必要です。
Unixでは既存ファイルのpermission bitsを引き継ぎ、新規出力は通常のファイル作成と同じumaskを適用します。

不正な開始フラグ、途切れたレコード、HCPの復号失敗、不正な指し手、手数範囲外、I/Oエラーでは
非zeroで終了します。部分的なPSVを成功結果として公開せず、一時ファイルを破棄し、既存出力を保持します。
エラーがある対局・ファイルを飛ばすモードはありません。
