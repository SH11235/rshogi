# book_prepwalk

`book_prepwalk` は、相手が棋譜で即指しを続けた範囲 (相手の定跡) から相手の定跡の木を作り、
自分の YANEURAOU-DB2016 テキスト定跡 `.db` と交互に辿ります。相手の準備の中で自分が考え始める
局面と、そこから先に残っている相手の準備の長さ・出口の評価値を相手ごとに集計します。

```bash
cargo run --release -p tools --bin book_prepwalk -- \
  --lines prepared_all.tsv \
  --book book.db \
  --out walk.tsv \
  --opponent Foo,Bar \
  --follow preset --preset book.random.explore.txt
```

## 入力

| 引数 | 説明 |
|---|---|
| `--lines <PATH>` | 相手の対局の一覧 TSV (下記) |
| `--book <PATH>` | 自分の定跡 `.db` |
| `--out <PATH>` | 止まった局面の一覧 TSV の出力先 |
| `--opponent <NAME>` | 相手の名前。大小文字を無視した部分一致で、カンマ区切り・複数指定可。1 局が複数の名前に一致すれば先に書いた名前に入れる。集計の相手名は小文字にした指定値 |
| `--our-side <black\|white>` | 自分の手番。既定 `white` (相手は先手で、名前は `black` 列と照合する) |
| `--follow <main\|all\|preset>` | 自分の手番で辿る手 (下記)。既定 `main` |
| `--preset <PATH>` | 局面ごとの乱択候補ファイル。`--follow preset` で必須 |
| `--override <PATH>` | 自分の手の差し替え TSV。複数指定可 (後のファイルが優先) |
| `--min-weight <F>` | 標準出力の上位表示に載せる重みの下限。既定 `0.005` |
| `--prune <F>` | 重みがこれ未満の枝は辿らない (止まり方「打ち切り」)。既定 `0.0001` |
| `--max-ply <N>` | この手数を超えたら辿らない (止まり方「上限」)。既定 `200` |
| `--self-name <NAME>` | 止まり方「`<NAME>` が読む」に使う名前。既定 `自分` |
| `--danger-remaining <N>` | 危ない進行の条件の、1 局の相手の定跡の残り手数の下限。既定 `40` |
| `--danger-eval <N>` | 危ない進行の条件の、同じ 1 局の出口の評価値 (相手から見た値) の下限。既定 `250` |

`--prune` は正の値、`--min-weight` は 0 以上でなければエラーにします。入力の TSV・差し替え TSV・乱択候補ファイルは改行が LF でも CRLF でも読めます。

### 相手の対局の一覧

1 行目が列名のタブ区切りで、次の列を使います (他の列は無視)。

| 列 | 内容 |
|---|---|
| `black` / `white` | 対局者名。相手の側の列を `--opponent` と照合する |
| `sente_book` | 相手の定跡が続いた手数 (初手からの通算手数) |
| `eval_sente_out` | 相手が定跡を出た直後の評価値 (先手から見た値)。空欄可 |
| `moves_csa` | 手順 (CSA 形式 `+7776FU` を空白区切り) |
| `winner` | 勝った側 (`b` / `w`、それ以外は引き分け扱い) |

`--our-side black` のときは、後手の相手の定跡を `sente_book` / `eval_sente_out` に入れた一覧を渡します。

### 自分の手の差し替え

`局面キー<TAB>手` の行です。局面キーは SFEN の盤面・手番・持ち駒の 3 フィールドです。手が空なら
その局面は定跡に無いものとして扱います。差し替えはどの `--follow` よりも優先します。
定跡に無い局面キーを差し替えたときは stderr に警告を出します (差し替え自体は行う)。

## 辿り方

平手から始め、重み 1 を枝に分けながら深さ優先で辿ります。

- 相手の手番: 相手の定跡の木にあれば、相手がその局面で指した手の局数に比例して重みを分けます。
  無ければ「相手の定跡が切れた」で止まります。
- 自分の手番: 定跡から下の規則で、その局面で合法な手を選び、重みを手の数で等分します。
  手が無ければ「`<self-name>` が読む」で止まります。非合法な手は辿らずに stderr に出し、
  標準出力に件数を出します。

| `--follow` | 自分の手番で辿る手 |
|---|---|
| `main` | 局面で合法な手のうち、値 (同値なら採択数) が最大の手。同点はファイルで先に書かれた手。値が -30000 以下の記録用の手は除く |
| `all` | 記録用以外の全ての手 |
| `preset` | 乱択候補ファイルに局面があれば、その手と定跡の合法な手 (記録用を含む) の積集合。積集合が空、または局面が無ければ `main` と同じ |

重みの等分がエンジンの指し方と一致するのは `preset` だけです (エンジンは乱択候補の局面で、積集合から
等確率で選ぶ)。`all` は定跡の全ての手を等確率で指すと仮定した場合の見積もりです。

`main` と、`preset` で候補が無い局面の手は、値が最大の手を決定的に選ぶ指し方 (`BookSelectValue=true`
相当、同点は先に書かれた手) を表します。エンジンの既定の採択数に比例した乱択、評価値の差・下限による
候補の絞り込み、先後反転局面の参照 (`FlippedBook`)、定跡を使う手数の上限は再現しません。
定跡の局面は手数を無視して引きます。

乱択候補ファイルはエンジンの `BookExploreFile` と同じパーサで読みます (`sfen <盤面> <手番> <持ち駒> [<手数>] <手> ...`、
`#` 行は無視、同じ局面の行は後の行を使う、同じ行の重複した手は最初の 1 つ)。USI として読めない手を含む行などの
不正な行はエンジンと同じく行ごと読み飛ばし、理由を stderr に、読み飛ばした行数を最後に出します。
先後反転した局面は引きません。

## 出力

### 止まった局面の一覧 (`--out`)

「相手の定跡が切れた」「`<self-name>` が読む」で止まった枝を 1 行ずつ、辿った順に書きます。

| 列 | 内容 |
|---|---|
| `opponent` | 相手名 |
| `weight` | 枝の重み (小数 4 桁) |
| `stop` | 止まり方 |
| `ply` | 止まった局面の手数 (次に指す手の番号) |
| `key` | 止まった局面のキー |
| `path` | 平手からの手順 (USI) |
| `games` | その局面を相手の定跡の範囲で通った対局数 |
| `max_remaining` | その局面から相手の定跡の終わりまでの手数 (両者の手を合わせた数) の最大 |
| `eval_out_median` | 通った対局の出口の評価値の中央値 (先手から見た値、偶数個は中央 2 値の平均を 0 方向へ切り捨て) |
| `eval_out_max` | 通った対局の出口の評価値のうち相手に最も良い値 (`--our-side white` は最大、`black` は最小) |
| `sente_winrate` | 通った対局での相手の勝率 (小数 2 桁) |
| `alt_moves` | `--follow all` / `preset` のときだけ。自分が `main` 以外を選んだ手を `手数:手` で並べる |

「相手の定跡が切れた」局面は相手の定跡の範囲に無いので、`games` 以降は 0 か空になります。

### 標準出力

相手ごとに、対局数・止まり方ごとの重みの合計、「`<self-name>` が読む」のうち重み `--min-weight` 以上の
上位 8 件、危ない進行の本数・局面数・重みの合計と重みの上位 8 件 (条件を満たす対局数 / 通った対局数と手順) を
出し、最後に危ない進行の合計本数を出します。

危ない進行は「`<self-name>` が読む」で止まった行のうち、その局面を通った対局の中に、相手の定跡の残り手数が
`--danger-remaining` 以上で、かつ同じ対局の出口の評価値が相手から見て `--danger-eval` 以上 (既定値なら
`--our-side white` で先手から見た値が `+250` 以上、`black` で `-250` 以下) のものが 1 局以上ある行です。
`max_remaining` と `eval_out_max` は別々の対局から来ることがあるので、この 2 列だけでは判定できません。
本数は手順の数なので、手順違いで同じ局面に着く行はそれぞれ数えます (局面数は重複を除いた数)。

相手の対局のうち CSA の手を再生できなかったものは、その手より前に通った局面だけを木に入れ、件数を表示します。
